About Kith & Kirr

Kith & Kirr, named for Kirr Commons and "kith and kin," is a theme for Grouper, Internet2's group management service. It brings Carnegie Mellon's web template and the Web Kilt to Grouper's web UI, and leaves Grouper itself as it is.

What It Changes

  • Header: the template's red roof with the Carnegie Mellon wordmark, search and the signed-in person's initials, then your site's name and the Grouper logo.
  • Footer: the template's dark footer with your site's name, the university's address, Help, Legal Info and www.cmu.edu.
  • Pages: light headings with the description as a lead, the Kilt's breadcrumbs and tabs, and the side menu as the template's link list.
  • Tables: the Kilt's tables with actions, with a selection count, a More button for each row and the Kilt's pager. On phones, each row stacks under its column's labels.
  • Forms and buttons: labels in small capitals above their fields, square fields, the main action as the template's button and the rest as ghost buttons.
  • Words: menus, tabs, buttons, headings and labels in Title Case, and plainer error messages.

The Demo Structure

The repository's demo/groups.yaml is a made-up Grouper structure for Buggy, the Spring Carnival Sweepstakes: drivers, pushers, teams and race officials, a Buggy app whose users are its allowed users minus its denied ones, and the Sweepstakes officers managing their own folder. In the repository, make run runs Grouper with the theme and loads it on your computer.

Contributing to Kith & Kirr

Kith & Kirr is a stylesheet, a header script and text settings for Grouper's web UI, built from the Web Kilt's npm package.

The GitHub repository has the theme's code and documentation. To report a problem or suggest a change, open an issue or send a pull request.
