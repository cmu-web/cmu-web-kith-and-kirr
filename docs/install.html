Install Kith & Kirr

You need access to Grouper's web app folder (/opt/grouper/grouperWebapp in Internet2's container) and a way to restart Grouper. The theme is tested with Grouper 7.9.1.

Using an AI coding agent? Set Up With an AI Agent

  1. Download kith-and-kirr.zip from the latest release and unzip it.
  2. Copy assets/kith-and-kirr/ to grouperExternal/public/assets/kith-and-kirr/, and customHeader.jsp over WEB-INF/grouperUi2/assetsJsp/customHeader.jsp, which Grouper ships empty for a site's own markup.
  3. Add the lines in the zip's properties/ files to Grouper's files of the same names: WEB-INF/classes/grouper-ui.properties, WEB-INF/classes/grouperText/grouper.text.en.us.properties and WEB-INF/classes/Owasp.CsrfGuard.overlay.properties. Keep the lines already there.
  4. Restart Grouper.

In a container, mount the files read-only or build them into your image. A file mounted on its own keeps pointing at the file it started with, so after changing one, write it in place or restart the container.

Your Site's Name

In grouper.text.en.us.properties:

  • kithAndKirr.siteTitle is the name in the header, "Grouper" unless your site calls it something else.
  • kithAndKirr.siteTagline is a line under the name. Leave it blank for none.
  • institutionName is the university's name in the footer.

Why the CSRFGuard Line

Once a page has loaded, Grouper's CSRFGuard script adds its token to the address of every stylesheet, script and image on it. A stylesheet whose address changes is dropped and downloaded again, so the browser can paint the page with Grouper's own styles before the theme's arrive. The line lists the static file types CSRFGuard leaves alone. The server checks tokens exactly as before; only static files stop getting one.

When Its Words Change

Grouper rereads its text file about every 10 minutes, but some text, such as the group summary's labels, is read only when Grouper starts. Restart Grouper after changing the theme's words to see all of them.

What It Touches

Only the places Grouper sets aside for a site: the empty customHeader.jsp, Grouper's settings files for a site's own values and a folder of its own under Grouper's public assets. Nothing of Grouper's is replaced or edited, so an upgrade keeps the theme. Check the pages you use after each Grouper upgrade, since the theme styles Grouper's own markup.
